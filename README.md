# Gol a Gol

Jogo de mesa para o celular: dois jogadores, um contra o outro, multi-toque. O dedo defende e chuta ao mesmo tempo.

**Gelo** vs **Brasa**. Deite o celular na mesa, cada um num gol.

## Como jogar

1. Abra o jogo no celular
2. Escolha dois jogadores (ou contra o bot)
3. Defina o tamanho do gol e quantos gols valem a partida
4. Cada um toca na sua metade — até 3 dedos
5. Arraste rápido para chutar; os círculos no campo dão boost

## Rodar localmente

```bash
npm install
npm run dev
```

Abre em `http://localhost:8080`. A landing fica na raiz; a partida em `/play`.
